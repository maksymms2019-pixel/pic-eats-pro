
# CalorAI — PWA для підрахунку калорій

Повноцінний додаток, де ти фотографуєш їжу, AI визначає страву й рахує калорії, білки, жири та вуглеводи. Працює як PWA — встановлюється на телефон і виглядає як нативний застосунок.

## Стек

Шаблон Lovable (TanStack Start) працює як SPA: команда збірки створює статичний `dist`, який деплоїться на Vercel/Netlify без додаткових конфігів. Серверні функції використовуємо лише як тонкий проксі до AI Gateway (щоб не світити ключ у браузері) — це стандартна практика, безкоштовна на Vercel/Netlify і не потребує ручних налаштувань.

## Що буде в додатку

### 1. Реєстрація та онбординг
- Email + пароль через Lovable Cloud
- Онбординг після першого входу: стать, вік, зріст, вага, рівень активності, ціль (схуднути / підтримувати / набрати)
- Автоматичний розрахунок BMR (Mifflin-St Jeor) і TDEE → денна ціль калорій і БЖВ (40% вуглеводи / 30% білки / 30% жири, з коригуванням під ціль)

### 2. Розпізнавання їжі з фото (основна фіча)
- Кнопка камери внизу екрану
- Знімок або вибір з галереї → надсилається в Gemini Vision через Lovable AI Gateway
- AI повертає: назву страви, орієнтовну вагу, калорії, білки, жири, вуглеводи, впевненість
- Користувач може скоригувати порцію (слайдер ваги) перед збереженням
- Запис додається в денний щоденник

### 3. Сканер штрих-кодів
- Камера з детектором (бібліотека `@zxing/browser`, повністю в браузері)
- Зчитаний код → запит до Open Food Facts API (безкоштовно, без ключа) → продукт + БЖВ
- Користувач вводить грами → запис у щоденник

### 4. Ручне додавання та база продуктів
- Пошук по локальній базі продуктів + по Open Food Facts
- Створення власних страв (інгредієнти + ваги → сумарні БЖВ)
- «Улюблені» для швидкого повторного додавання

### 5. Денний щоденник і прогрес
- Головний екран: кільця прогресу (калорії / Б / Ж / В) проти цілі
- Список прийомів їжі за день (сніданок / обід / вечеря / перекуси), кожен запис із фото-прев'ю
- Свайп для видалення, тап для редагування порції
- Графік за тиждень/місяць
- Календар із позначками днів, де ціль виконана

### 6. AI-нутриціолог (чат і рецепти)
- Чат-вкладка з потоковими відповідями від Gemini
- Контекст: профіль користувача, його ціль, що з'їв сьогодні
- Кнопки швидких запитів: «Що приготувати з залишку калорій?», «Рецепт на 400 ккал з куркою», «Як добрати білок сьогодні?»

### 7. PWA
- Web App Manifest (іконки, splash, theme color, standalone)
- Встановлення на iOS / Android home screen
- Без офлайн-режиму (бо AI потребує мережу) — тільки інсталяція як додаток

## Дизайн

Сучасний мінімалізм у стилі здорового харчування: світла основа, м'які зелені акценти для прогресу, великі цифри, кільця прогресу як на Apple Watch. Темна тема. Mobile-first, але адаптивно під десктоп.

## Технічна частина

```
src/routes/
  index.tsx              → редірект (auth → /app, без auth → /auth)
  auth.tsx               → вхід / реєстрація
  reset-password.tsx     → скидання пароля
  onboarding.tsx         → перший вхід: дані для розрахунку цілі
  _app/                  → захищений layout
    today.tsx            → щоденник за сьогодні + кільця
    scan.tsx             → камера: фото або штрих-код
    diary.tsx            → історія, графіки, календар
    foods.tsx            → база продуктів, улюблені, мої страви
    coach.tsx            → AI-чат
    profile.tsx          → налаштування, ціль, вихід
  api/
    analyze-food.ts      → проксі: фото → Gemini Vision → JSON
    coach.ts             → проксі: стрім чату з контекстом
```

База даних (Lovable Cloud):
- `profiles` — стать, вік, зріст, вага, активність, ціль, цільові калорії/БЖВ
- `food_entries` — записи в щоденник (user_id, дата, прийом їжі, назва, грами, ккал, Б/Ж/В, фото)
- `custom_foods` — користувацькі продукти/страви
- `favorites` — швидкий доступ
- RLS на всіх таблицях: користувач бачить лише свої дані
- Storage bucket для фото їжі

Інтеграції:
- Lovable AI Gateway (Gemini 2.5 Flash для vision, Gemini 3 Flash для чату)
- Open Food Facts API для штрих-кодів (публічний, без ключа)
- `@zxing/browser` для сканування

## Що поза скоупом цього кроку
- Push-сповіщення
- Інтеграція з Apple Health / Google Fit
- Соціальні фічі (друзі, лідерборди)
- Оплати / преміум

Можемо додати в наступних ітераціях після того, як основа працює.
