# CalorAI 2.0 — фінальне «вау»-оновлення

Мета: зробити застосунок таким, щоб після відкриття одразу було видно «це інший рівень». Не просто косметика — нові смисли, краща точність, нові екрани, нова поведінка.

---

## 1. Концепт

Три великі ідеї, які тримають усе оновлення разом:

1. **«Сьогодні» як живий дашборд, а не список.** Кільця + прогноз дня + поради + швидкі дії + останні страви + контекст води/ваги.
2. **AI, якому можна довіряти.** Сканер чесно каже, що бачить, а що — припускає. Брендові продукти йдуть через базу. Користувач легко править вагу/склад одним свайпом.
3. **Мотивація без токсичності.** Streak днів, тижневий огляд, м'які досягнення, AI-коуч який пам'ятає контекст і пропонує конкретні дії, а не загальні фрази.

---

## 2. Що нового по екранах

### Home / «Сьогодні» (повний редизайн)
- Великі кільця ккал/Б/Ж/В + цифра «залишилось» по центру.
- Стрічка прогресу дня: сніданок → обід → вечеря → перекус, заповнюється в міру записів.
- Блок **«Прогноз дня»**: якщо темп такий же, до вечері буде X ккал → підказка («можна додати ~40г білка»).
- **Streak-бейдж** (🔥 N днів поспіль) + швидка кнопка «лог води» (стакани).
- Карусель **«Швидко додати»**: останні 6 страв одним тапом.
- Список записів по прийомах їжі з свайпом: видалити / редагувати грами / в обране.
- Перемикач дат (← сьогодні →) із індикатором виконання цілі.

### Scan (інтелект)
- Один великий CTA + три тихі режими: **Фото / Штрихкод / Назва**.
- Після аналізу — картка результату з **довірою (low/medium/high)**, бейджами `видно на фото` vs `припущення`, кнопкою **«Уточнити»** (вільний текст → переаналіз із попереднім контекстом).
- Якщо брендовий продукт → джерело «Open Food Facts», лінк, бренд, вага упаковки.
- Якщо `needs_clarification` → коротке питання чіпами («з олією?», «з майонезом?»).
- Поділ на items: можна **видалити зайвий компонент** (бутерброди без «печива») і ккал перераховуються миттєво.
- Вибір прийому їжі (chip-група) + грами слайдером з живим перерахунком.

### Diary / Тиждень (новий екран)
- Heatmap 7 днів × ккал, бари по днях.
- KPI: середнє ккал, дотримання цілі (%), найкращий день, найгірший день.
- Тижневий summary від AI (одна абзацна порада, кешований).

### Coach (покращення)
- Передвстановлені швидкі питання: «Що з'їсти на вечерю?», «Чи дотягую білка?», «Розбери мій день».
- Передає контекст профілю + сьогоднішніх записів + цілі (вже частково є — добити).
- Markdown-рендер, копіювання відповіді, історія в межах сесії, кнопка «очистити».

### Foods (покращення)
- Вкладки: **Обрані / Останні / Свої**.
- Пошук, сортування за частотою, кнопка «+1 порція» прямо з картки.
- Створення власної страви руками (без фото) із розрахунком на 100г.

### Profile
- Картка прогресу до цілі по вазі (якщо є `target_weight`).
- Швидке редагування цілей (ккал/Б/Ж/В) із попередньою формулою як підказкою.
- Темна тема toggle, мова (поки укр), вихід.

### Onboarding
- Прогрес-бар, плавні переходи, фінальний екран з ціллю та поясненням «звідки ця цифра».

## 3. AI / точність (головне)

- **Анти-галюцинація**: чітко розділити `visible_items[]` і `assumed_items[]` у схемі інструмента; на UI показати бейджами.
- **Брендові** → завжди Open Food Facts; якщо не знайдено — `low` + питання користувачу, без вигаданих цифр.
- **Стабільність**: `temperature: 0`, `seed: 42`, фіксований системний промпт, кеш по hash фото+підказки (24 год) — однакове фото = однакова відповідь.
- **Sanity-чеки**: Б×4+В×4+Ж×9 ≈ ккал (±10%), ккал/г у межах 0.2–9.0.
- **«Уточнення» як справжній diff**: попередня відповідь + правка користувача → перерахунок, не з нуля.
- **Multi-photo**: перше — головне, решта — етикетка/масштаб.

---

## 4. Гейміфікація (легка, без тиску)

- **Streak** днів із записами (рахується на клієнті з `food_entries`, бейдж 🔥).
- **М'які досягнення** (локально, без нової таблиці спершу): «3 дні поспіль», «7 днів», «потрапив у ціль білка», «перший штрихкод».
- **Тижневий огляд** у неділю ввечері (банер на Home).

---

## 5. Дизайн-система

- Єдина палітра через `src/styles.css` (HSL-токени): `--bg`, `--surface`, `--surface-2`, `--text`, `--muted`, `--primary`, `--accent`, `--success`, `--warning`, `--danger`, `--ring`.
- Темна тема за замовчуванням (food-app vibe), світла — опційно.
- Один шрифт-пейр: заголовки — `Space Grotesk`, текст — `Inter`.
- Рух: лише `framer-motion` для появи кілець, лічильника ккал (count-up), свайпів у списку.
- Haptics-like мікроанімації на кнопках, скелетони замість спінерів.
- Іконки — `lucide-react`, без надмірності.

---

## 6. PWA / якість

- `manifest.webmanifest` (вже є) → додати правильні іконки 192/512, theme-color, `display: standalone`.
- `apple-touch-icon`, splash, safe-area paddings.
- Офлайн-fallback для останніх записів (read-only з кешу React Query).
- Lighthouse: SEO/Best Practices/Accessibility ≥ 95.

## 7. Технічна частина (коротко для розробника)

- Без зміни стеку: React + Vite + Tailwind SPA, Supabase Edge Functions (`analyze-food`, `coach`).
- Нові/змінені файли (план, не виконання):
  - `src/routes/today.tsx` — повний редизайн.
  - `src/routes/scan.tsx` — UI результату, items-editor, режими.
  - `src/routes/diary.tsx` — тижневий огляд + heatmap.
  - `src/routes/coach.tsx` — швидкі питання, markdown.
  - `src/routes/foods.tsx` — вкладки, ручне додавання.
  - `src/routes/profile.tsx` — прогрес ваги, редагування цілей.
  - `src/components/`: `Rings`, `StreakBadge`, `QuickAdd`, `MealStrip`, `WeeklyHeatmap`, `ItemRow`, `ConfidenceBadge`, `WaterTracker`, `EmptyState`, `Skeleton*`.
  - `src/lib/streak.ts`, `src/lib/format.ts`, `src/lib/achievements.ts`.
  - `supabase/functions/analyze-food/index.ts` — розділення visible/assumed, кеш по hash, жорсткіша валідація.
  - `supabase/functions/coach/index.ts` — багатші контексти, краща system-prompt.
  - `src/styles.css` — нові токени, темна тема.
- БД: мінімально. Якщо потрібен лог води — нова таблиця `water_logs` (id, user_id, date, ml) з RLS + GRANT.
- Без SSR, без TanStack Start. Збірка `vite build` → статичний `dist`, як зараз.

## 8. Порядок виконання

1. Дизайн-токени + темна тема + базові компоненти (`Rings`, `Skeleton`, `EmptyState`).
2. Перебудова `today` (дашборд, streak, швидко додати, прийоми їжі).
3. Перебудова `scan` (items-editor, confidence, режими, уточнення).
4. Бекенд `analyze-food`: visible/assumed, кеш, валідація, OFF.
5. `diary` — тижневий огляд + heatmap.
6. `coach` — швидкі питання, markdown, контекст.
7. `foods` + `profile` доопрацювання.
8. PWA-поліровка, мета, іконки, перевірка на iPhone (390px).

## 9. Що зумисно НЕ робимо зараз

- Соцфічі/друзі/спільний рейтинг — не на цьому етапі.
- Підписки/платежі.
- Окремий бекенд для досягнень (тримаємо локально, поки не виправдається).
